Este es un trabajo en el que apliqué el patrón Abstract Factory a una fábrica de pizzas. Básicamente lo que hice fue ordenar el código para que no estuviera tan acoplado, ahora si se quiere cambiar el tipo de masa, sea delgada, gruesa o integral, solo se cambia la fábrica y listo, sin tener que moverle nada a la lógica que prepara la pizza.
